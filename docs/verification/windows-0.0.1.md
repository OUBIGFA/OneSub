### 行为证据

- **供应商和模型**：新增、命名、切换及重启恢复各供应商的模型与声明上限通过回归。缺失模型参数保持未知；新供应商的凭据范围相互独立。Chat Completions 与 Responses 的实际 HTTP 测试均核对输出上限参数。
- **独立字幕**：AI 将两条原始字幕合为一条后，原始轨仍保留两条。修改原始轨、撤销和重开不改变重建轨；版本 1 工程先备份，再恢复首次翻译前的原始分段。
- **导出**：原始字幕、重建原文、译文及双语分别经真实字幕 worker 写入、回读 SRT/VTT；分段、文字及四种默认文件名均与选择一致。
- **中断与重启**：`tests/e2e/translation_provider.py --packaged --interrupt` 对包内程序执行真实导入、播放、设置切页、断流、测试进程意外退出、启动恢复、重试、保存和撤销。第一条完整译文与第二条未完成文字在中断和重启后仍可见；第一次请求包含两条，重试只包含第二条，总计 2 次本地请求。该项不代表云端翻译质量评测。
- **失败保护**：工程写入失败时保留结果与重试入口；设置文件损坏时恢复流程不覆盖它；进度文件不含 Key。取消测试的服务夹具正确处理被取消的半截请求，不再访问空消息数组。
- **界面**：编辑、样式标题及时间参数居中；供应商和模型在工作台直接选择。900×640 中英文界面的设置控件可见，供应商状态变化不改变对话框尺寸；包内中文真实窗口已截图核对。

源码及包内回归与桌面验收使用自制字幕和测试音视频。安装、覆盖更新、卸载及其余 P0 门禁仍按文末范围待实测。
