# Windows 工作台完善记录

## 行为与复用

- MyGo `RequestSingleInstanceLock`、`OnSecondInstance`、`Restore/Show/Focus`：重复启动、最小化和托盘隐藏均唤醒原窗口，不创建第二套工作台。
- 子进程经统一入口配置 `CREATE_NO_WINDOW` 与隐藏窗口；Job Object 仍负责长任务的进程树取消。
- SmartSub 字体族别名修复、完整字重交付、双语事件和背景框精确边距见 [补丁登记](../../third_party/ports/smartsub/README.md)。系统字体目录元数据变化触发目录刷新，不需要重启；可手工刷新，不重置用户样式。
- 字幕编辑实时写入字幕列表（工程工作副本，可撤销）；写入字幕文件只经字幕列表的“保存”“另存为”。每条轨道按内容 SHA-256 与最近一次保存比较，撤销回保存时的内容后不再显示“未保存”。打开文件或工程、重新识别、清空工作台和退出前询问保存／不保存／取消；隐藏到托盘不询问。保存先写同目录临时文件再替换，失败时原文件不变。
- 手改译文锁定该句译文；修改原文不锁定，修正识别错误后仍可翻译。
- 单击／双击行为参照 Subtitle Edit `SettingsViewModel` 的独立动作设置，提供仅选择、定位保持状态、定位暂停、定位播放。Avalonia UI 未移植到 MyGo。
- 软字幕封装与硬字幕烧录使用通行术语；进度参照 SmartSub `composeRunner` 的真实媒体时间/总时长计算，校验完成前不宣称任务成功。“原画质（无损）”使用 libx264 `-qp 0`，x264 支持源像素格式时保持不变。
- 播放器：WebView2 默认背景与播放页均为黑色；播放页始终按播放器尺寸布局，载入视频只改变 `src`。“首次拖入视频时画面靠左、无背景”未在测试环境复现；原实现在首个视频载入时才放入网页视图，现已去掉这一差异。
- 播放器右键：页面屏蔽 WebView2 自带菜单；透明的原生覆盖层提供 MyGo 菜单，文字随界面语言。单击覆盖层播放/暂停。
- 托盘：MyGo 托盘 `OnClick` 在左键抬起时触发，双击包含两次抬起，所以单击和双击都打开主窗口。
- 界面语言：MyGo i18n 目录（ARB / ICU MessageFormat）提供 zh-Hans 与 en，`SetLocale("")` 跟随系统。WebView2 的语言在创建首个网页视图时确定，所以启动时先应用语言设置。worker 只返回稳定错误码（`E_…`），由桌面端按界面语言显示。
- 序号列以当前字体测量最大位数，并包含表格内边距。保留完整工程编号容量，不按筛选后的行数收缩。

## 布局回归

文件选择时的“取消任务”按钮原先令状态栏变高，挤压百分比分隔面板。现在状态栏高度稳定，文件窗口不显示后台任务取消按钮。测试比较内部播放器边界，不只比较外层窗口尺寸。

设置按功能分组，常规、识别与模型、翻译三页同高；数值输入不能小于 MyGo 输入框与两个步进按钮的固有宽度，否则相邻标签重叠。播放器按钮的图标在按钮内居中，按钮、进度条与音量单行排列，文件名居中。“识别字幕”位于播放器标题栏左侧，“翻译字幕”位于字幕标签栏左侧，“原文 / 译文”标签居中。字幕列表行高随内容自适应。空区域的提示居中并使用主题次要文字色。

## 可复现验收

- `build/test.ps1`：先生成消息目录，再运行真实 worker/FFmpeg、源译文事务、保存与未保存确认、序号列、布局、双语切换、字体族及字重、背景框事件结构、字体目录变化、模型列表协议与无控制台 helper 回归。
- `tests/e2e/translation_provider.py`：本地模型列表与翻译服务、真实播放/暂停、设置分页、暂停帧粗体、译文接受与撤销。
- `tests/e2e/workbench_polish.ps1`：可见/最小化/托盘三种单实例唤醒、实时编辑与列表保存、源译文独立、清空前的未保存确认、内部区域边界、真实合成进度和输出命名。

两个桌面脚本按中文界面查找控件，并固定 `uiLanguage` 为 `zh-Hans`。它们会在桌面打开可见窗口和文件对话框，本轮已按当前界面更新，未重新运行。
