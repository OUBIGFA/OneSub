# 工作台与字幕翻译实施计划

目标：设置、识别、导出与翻译在同一原生工作台中可直接操作，时间轴候选经过核查后作为一次可撤销修改接受。

当前 Agent 在现有工作区独立实施。沿用 MyGo 原生控件和 Lucide 图标、OneAsr 识别与模型目录、SmartSub 字体和 ASS 模块、完整 srt-subtitle-translator。保留未提交改动，不创建分支或发布。

## 翻译与输出

- [x] 设置按最高内容自适应；合并识别与模型，按识别、强制对齐、热词、人声分离分类；修复按钮与菜单。涉及 `apps/desktop/settings_view.go`、`main.go` 和 MyGo 的最小兼容补丁。用原生布局与桌面实测核查。

- [x] 领域风格以 SKILL.md 加载，保存选择；完整核心规则始终生效。涉及 `internal/translator`、翻译视图与设置。验证新增、修改、删除风格无需重启且不执行脚本。
