## 本次已取得的行为证据

- 原生工作台：上部视频与字幕列表，下部字幕编辑与字幕样式分区；字幕列表有原文、翻译两个标签。未翻译内容不回填为译文。
- 样式：完整 Style 字段变更都会触发预览失效；粗体、斜体、字体、字号、颜色、边框、透明度、阴影、位置及左/右/垂直边距共用 SmartSub 构建管线。140 ms 合并输入，不占用主任务忙状态；过期构建结果不会回写新版本。同一字体集合通过 JASSUB setTrack 更新，不重建 canvas。
- 真实桌面：合成测试视频的首帧、播放、暂停、同名字幕加载可用；暂停帧勾选粗体后，视频区域像素发生变化，已回读截图确认字幕重绘。
- 设置：常规、识别、模型、翻译四页在实测窗口中无需滚动；模型页使用选择器而非重复堆叠所有模型参数。截图已逐页回读。
- 窗口：首次根据当前显示器可用 DIP 区域计算尺寸，避开任务栏；超宽屏限制宽高比。MyGo StateKey 保留已有用户窗口状态。
- 翻译：本地 HTTP 协议夹具 → 原技能检查器 → 桌面候选接受 → 字幕显示及真实预览更新 → 撤销，完整操作链通过。该夹具不是实际大模型翻译质量测试。
- 凭据：Windows 系统凭据的保存、读取、端点隔离和删除已测试；Key 不进入设置 JSON 和候选报告。
- 字幕：联调发现并修复 SRT 序号全部为 0 的问题；真实 libse 与原技能检查器已覆盖序号、时轴和标记保护。

## 可复现入口

- `build/native-preview.ps1`：原生窗口开发验证；不制作安装器。
- `build/test.ps1`：Go、真实字幕 worker、仓库检查和仓库测试。
- `build/test.ps1 -PackageRoot <打包目录>`：同一测试使用包内 worker 与 FFmpeg，而非 PATH 替代品。
- `tests/e2e/translation_provider.py`：真实原生窗口、播放、四页设置、粗体自动预览、受控本地翻译请求、候选接受和撤销。输入为自制测试音视频，不使用私人媒体。
- `build/build-windows.ps1 -BuildNumber <内部构建号>`：固定安装器 `OneSub-0.0.1-Setup.exe`，附 SHA-256 与构建信息；已存在的内部包目录不覆盖。

桌面环境：Windows build 26220，WebView2，实测屏幕可用区域 3440×1392 DIP。首个固定 1280×840 窗口布局已替换；本次按屏幕计算的窗口为 2504×1252 DIP。多显示器和不同缩放通过几何单测不等同全部桌面实测。
