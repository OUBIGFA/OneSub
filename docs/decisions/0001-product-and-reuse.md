# 0001：原生字幕工作台与组件复用

日期：2026-10-27 · 状态：实施决策；各能力以验收记录为准

## 目标

在同一个工作台完成添加、识别、翻译、校对和合成。视频添加后直接可播放；已有字幕立即可编辑，不要求命名工程或进入准备页。界面只用成熟控件，常用动作可见，高级参数按需展开。

## 技术路线

1. **MyGo 原生 UI**：窗口、控件、分隔布局、表格、主题、图标渲染和托盘。
2. **Concat**：真实工作台布局与编辑交互标杆；按源码符号移植手势/历史逻辑，不移植 Slint 自绘控件或无关特效引擎。
3. **Subtitle Edit/libse**：直接编译独立 .NET worker，处理字幕解析、格式保护、转换及修复提案。
4. **SmartSub**：提取纯样式模块作为唯一 ASS 生成器；合成计划按 P0 范围复用/移植。没有 Electron 主应用，没有常驻 Node 服务。
5. **OneAsr**：直接复用 core/CLI、模型目录及下载校验语义。有限补丁只处理协议、任务目录、共享模型路径和产物可靠性。
6. **srt-subtitle-translator**：完整快照作为翻译规则与组装/检查内核，应用内助手执行明确的桌面适配工作流。

具体修订、文件和边界见 [源码核查](../research/implementation-reuse.md)。图标和其他第三方文件单独登记许可；自有代码采用 AGPL-3.0-or-later。

## 界面与媒体

操作界面全部使用 MyGo 原生控件和主题，不自行绘制元素。视频/ASS 渲染允许使用嵌入媒体视图，但不能让其变成另一套 HTML/CSS 界面。播放、暂停、定位和音轨控制仍是原生工作台的一部分。

主布局借鉴 Concat 的内容同屏原则：上部画面及属性，下部单一字幕表格，顶部主动作。播放首帧、手改及合成结果均以真实运行验证；文件路径不等于播放器，静态 CSS 文字不等于 ASS 渲染。

## 数据与执行

Go 是工程和任务的唯一写入者。导入自动建立恢复工程；原始文件保留，编辑和候选有 revision，手改有锁，至少 200 组撤销。后台结果不覆盖新修改，检查失败不生成假成功。

模型与设置位于稳定用户数据目录。设置提供关闭即退出/托盘、每模型目录与下载、OneAsr 适用参数、翻译服务及输出。缺失配置只阻止依赖它的动作，不阻止播放器或手工字幕流程。

## 取舍

| 不采用的做法 | 原因 |
| --- | --- |
| MyGo 仅作 Web 壳，另写界面控件 | 不能满足原生控件复用与一致交互约束 |
| 整体嵌入 Concat、Subtitle Edit 或 SmartSub 窗口 | 会引入多套状态、窗口和不需要的产品功能 |
| 重写字幕格式、ASR、翻译检查规则 | 丢失成熟实现和可追溯的回归依据 |
| 将所有配置放在开始前的向导中 | 阻塞添加即播放，也增加初次使用负担 |
| 为“简单”隐藏失败或静默删流/删句 | 破坏成果可信度与源文件保护 |

验收顺序见 [实施计划](../roadmap.md)。安装器固定为 `OneSub-0.0.1-Setup.exe`，内部构建号与 SHA-256 区分测试包；没有实际证据的能力不标为完成。
