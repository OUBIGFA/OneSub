# 实施顺序与验收

状态：实施与验收计划 · 2026-10-27

组件源码复核见 [复用核查](research/implementation-reuse.md)。工作区已有配对、字幕 worker 和工程事务的局部验证；这些证据不证明原生工作台或完整 P0 已可用。下列门槛仍需按最终打包组件逐项取得证据，不用总完成率掩盖缺口。

首个安装测试目标为 Windows x64 **0.0.1**，按 G0–G3 完成 P0 闭环。安装器文件名固定为 `OneSub-0.0.1-Setup.exe`，应用标识与安装目录稳定；后续测试构建仍更新此安装器，采用内部构建号和 SHA-256 区分，不伪装成同一二进制。覆盖安装保留工程、设置、Key 与模型；卸载不删除用户成果。固定文件名不等于跳过发布检查或自动安装。

## 1. 阶段依赖

| 阶段 | 动作与产物 | 通过条件 | 失败时处理 |
| --- | --- | --- | --- |
| G0：依赖与可行性 | 冻结六个项目的修订与许可；编译 MyGo 原生控件/媒体薄链路、libse、OneAsr、样式 worker 与技能检查 worker | 原生窗口可操作，视频真实首帧/播放/暂停可用；记录包体、下载、CPU 路径及许可证边界 | 记录具体兼容或授权问题；不以 Web 演示、空按钮或静态预览代替 |
| G1：原生工作台与手工闭环 | MyGo 原生工具栏、分隔面板、播放器、单列表及属性；导入自动恢复工程、双向配对、编辑/撤销、设置及托盘 | 添加即播放，无准备页/命名向导；字幕立即可编辑；退出/托盘及设置持久化通过；无模型/Key 可保存、重开、导出 | 入口、草稿或格式保护未过不得增加复杂 AI 流程；保留已有事务 |
| G2：识别与翻译 | 音轨选择、模型管理、真实 timeline、技能适配、术语预审、候选锁与版本检查 | 端到端短片可运行；静音不产生已验收对白；无时间锚点不自动切轴；旧候选不覆盖手改 | 结果标失败/待审，保留旧版本；禁止回填原文冒充翻译 |
| G3：完整 P0 | ASS 保护、字体、只读波形、交互预览、软字幕和 SDR 烧录、5 秒样片 | 格式、时轴、流保留、退出恢复、易用性和隐私矩阵通过；形成 Windows x64 可分发包 | 未过的关键场景阻止发布；不能只交字幕文件便称完整 P0 |
| G4：P1 工作台 | 批量、边界编辑、强制对齐、八类翻译风格、术语/记忆库、多语审阅及交付包 | 每项有真实用户场景和独立回归；重跑仅影响相关阶段；系列工程术语一致 | 小批交付，保持 P0 稳定；P1 仍是产品计划的一部分 |
| G5：平台与发行 | macOS Apple Silicon、Linux x64 分别构建、签名/校验、安装与升级测试 | 每个平台有独立记录；第三方源码、许可和 SBOM 与包一致 | 未过的平台不列为支持；Windows 10 只声明实测具体版本 |

G0→G1→G2→G3 为 P0 的主要依赖。G4 与 G5 可在 P0 稳定后分别推进。P2 功能另立规格，不用无限增加功能拖延已有闭环。

### 1.1 连续实施顺序

1. 建立 MyGo 原生窗口与组件测试；原生工具栏、分隔布局、表格、TextArea 和设置窗口全部使用框架控件。验收空界面没有准备页、欢迎卡片或装饰说明。
2. 接统一导入、自动恢复工程和真实播放器；分别验证四种入口、唯一候选、多候选、候选损坏和纯字幕。主文件先可用，不因模型缺失或配对失败阻塞。
3. 接 Concat 手势/历史复用及 libse 编辑闭环；保留源文件、锁与 revision，覆盖 200 组撤销、组合输入、失败草稿和重开。移植登记到具体符号及回归。
4. 接设置/托盘和模型管理；逐模型选择、目录、下载/续传/哈希、本地导入与删除保护。关闭行为持久化，托盘可恢复，运行中退出不丢状态。
5. 接 OneAsr 基座与真实音轨。生成 timeline，选定模型/参数确实传入任务；取消、GPU 故障、静音和首中尾时间映射有证据。
6. 引入完整字幕技能快照、应用内翻译适配和原检查器。首次服务配置后一个动作启动；按批审阅，缺译、过期、锁冲突及请求结果未知均不冒充成功。
7. 接 SmartSub 样式和合成模块。预览/烧录消费同一 ASS/字体；完成字幕、软封装、SDR 烧录、5 秒样片及流/时长/解码验证。
8. 从统一入口构建固定名称安装器；核对依赖许可、源码材料、签名状态、SHA-256。实测安装、覆盖更新和卸载保留数据；形成逐项验收记录后交付安装实测。

步骤完成后继续下一依赖，不把计划或中间界面截图当交付。需要外部服务账号/人工验收时仅隔离依赖部分，继续其他工作；最终状态如实区分已实现、已验证和待实测。

## 2. 数据与失败测试矩阵

| 对象 | 代表性输入或故障 | 可观察结果 |
| --- | --- | --- |
| **首要导入流程** | 拖入视频/拖入字幕/添加视频/添加字幕；同目录唯一同名配对；同时拖入一对 | 四种入口都自动加载另一文件，无第二次选择；视频真实可播放/暂停；不弹命名或准备向导；无模型/无 Key 可用 |
| 设置与托盘 | 关闭即退出/托盘、运行中关闭、托盘恢复/退出、重启 | 行为与已保存设置一致；退出前处理任务和草稿；托盘失败不隐藏窗口 |
| 模型 | 各模型目录、选型切换、断网续传、取消、损坏/缺失文件、本地导入 | 下载与加载指向同一目录；大小/哈希通过才就绪；旧模型保留；不阻塞无关编辑功能 |
| 配对边界 | 多种同名扩展名、不同目录同名、相似章节名、语言后缀、中文空格/大小写、候选损坏/删除/无权限、已有手改 | 多候选显式选；不跨目录或截短名称误配；候选失败保留主文件；已有内容先处理保存；不自动识别/上传 |
| 格式 | SRT/VTT 的 BOM、CRLF、ID、settings、NOTE；ASS 的 Comment、未知 section、绘图、karaoke、多层重叠 | 原始字节仍在；严格模式只回填允许的文字，受保护字段和顺序不变；不支持的结构明确报告 |
| 时间 | VFR、负 PTS、非零起点、多音轨偏移、时间戳不连续、尾部对白、ASS 厘秒量化 | 首中尾与参考锚点一致；无二次偏移；量化后非法时长阻止该目标导出 |
| 翻译 | 否定、条件、数值单位、快捷键、混合语言、跨批接缝、过长句、字幕中的指令文字 | 来源范围无漏无重；事实和受保护字面串保留；无证据不细切；字幕内容不能改变执行规则 |
| 人工成果 | 任务运行时编辑、锁定、撤销、重做、解锁、重新识别、导入外部审校包 | 基准版本冲突可见；旧候选不覆盖新内容；撤销恢复对应锁；无 ID 回导先显示匹配预览 |
| 持久化 | 保存时崩溃、磁盘满、数据库迁移失败、两个实例打开同一工程 | 已确认提交可恢复；保存失败保留草稿；失败迁移保留旧库；活动写者不被抢占 |
| 任务 | 取消、休眠、GPU 丢失、helper 崩溃、外置盘拔出、关闭窗口 | 状态准确；只终止本任务进程树；未验收 partial 不变成正式结果；能重跑相关阶段 |
| 导出 | MKV/MP4、多音轨、章节、字体附件、语言/default/forced、同名/别名目标 | 无静默丢流或覆盖；样式损失先确认；产物经 ffprobe 与解码检查才发布 |
| 隐私 | 无网络、未配置服务、401/429、请求读超时、诊断包、资源路径穿越 | 离线编辑仍可用；计费结果未知不自动重发；无 Key/全文/机器路径泄漏；越界资源访问失败 |

测试夹具优先使用可公开的自制短字幕与合成音视频；大型或第三方语料仅提交来源、授权与哈希清单。禁止把私人课程当默认回归附件。

## 3. 性能与质量记录

G0 确定并公布 Windows x64 参考机的 OS build、CPU、RAM、GPU、驱动、磁盘及显示缩放。不同硬件的结果不混成一个速度指标。

- 20,000 条 cue 下，常用选择/编辑操作到可见反馈的 p95 目标不超过 100 ms；记录采样方法，不把网络等待算作界面卡顿。
- 停止输入后 1 秒内发起自动保存；只有事务成功后显示已保存。至少 200 组撤销，记录峰值内存。
- 识别报告包含输入分钟数、冷/热启动、实时因子（处理秒数/音频秒数）、RAM/VRAM 峰值、下载量与失败率。G0 实测前不承诺 CPU 实时识别。
- 中文、英文、粤语、日语、韩语先建立有人工参考的评测集，报告 CER/WER、时间边界误差和静音幻觉；语言范围扩展须增加对应语料。引擎有入口不等于质量合格。
- 翻译报告分开列结构错误、语义抽检、术语、数值/否定错误和人工返工量。没有参考集时不编造“准确率”。
- 对照 whisper.cpp/faster-whisper 时固定输入、语言、硬件与解码设置；性能与质量分开比较，实验用引擎不随产品默认分发。

## 4. 易用性与发布放行

[交互验收](ui-design.md)要求至少 5 名目标用户中 4 名在 8 分钟内独立完成短样例；同时覆盖仅键盘、NVDA、100%/150%/200% 缩放、浅深色及无模型状态。此目标尚未实测。

每个阶段的记录包含测试版本、输入哈希、环境、命令或操作、预期与实际、错误/警告、人工检查者和未覆盖项。图形预览需实帧核验，Mermaid 设计图的可渲染性不代表应用已实现。

产品发布同时需要功能矩阵、[安全与分发](security-and-release.md)门禁、许可证材料、干净机器安装/升级/卸载和失败回滚。仅 CI 绿色或程序能启动均不足以放行。当前仓库 CI 只验证文档和仓库卫生。
