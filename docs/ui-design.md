# 界面与交互设计

状态：设计规格，非已实现界面 · 2026-10-26

## 1. 设计目标

**看得懂下一步、找得到问题、改完不会丢、交付前知道后果。**

不以参数数量体现专业性。常用操作在主界面，高级参数按需展开；一处只保留一个主要动作。界面默认简体中文，可切换语言；资源字符串外置，布局能容纳较长翻译。

采用平面分区、留白和细分隔，避免层层卡片、厚重阴影与纯装饰动效。正文推荐 15–16 CSS px，辅助信息不低于 13 px；不使用浅灰小字承载重要限制。标题中等字重，图标始终有文字或可读标签。

## 2. 信息架构

主导航只保留 **准备、编辑、导出**。它们是可返回的工作区，不是必须重做前面步骤的单向向导。

- 工程菜单：新建/打开、另存快照、打包、最近工程。
- 准备：媒体与字幕、试听音轨、源语言、识别/翻译任务。
- 编辑：一个主字幕列表、预览、问题过滤、术语及样式面板。
- 导出：交付用途、预检、5 秒样片、导出队列。
- 任务：全局入口显示运行/失败数，抽屉内有阶段与修复动作。
- 设置：模型与存储、翻译服务、外观与快捷键、隐私及诊断。

“安装包、模型、工程、缓存、导出”在存储页各自统计；清理按钮明确影响范围，不能用一个“清理全部”混删用户成果。

## 3. 首次使用

空白首页提供三个直白入口：**生成字幕、翻译已有字幕、仅校对与导出**。拖放区域与文件选择按钮并存；拖入不认识的格式时说明支持范围，不显示不可用的空白面板。

主拖放区写“拖入视频或字幕，自动查找同目录同名文件”，旁边始终提供“添加文件”。工作台的视频区与字幕区均接受这两类文件，类型判断与添加按钮共用入口，不要求用户拖到特定小区域。

| 操作与目录内容 | 界面结果 |
| --- | --- |
| 添加 `课程01.mp4`，同目录有唯一 `课程01.srt` | 视频与字幕一起就绪，直接进入校对；提示已自动加载字幕，不弹确认框 |
| 添加 `课程01.srt`，同目录有唯一 `课程01.mp4` | 字幕列表和视频一起就绪；提示已自动关联视频，不要求再次选文件 |
| 同时拖入上述一对 | 合并成一次导入，不重复创建轨道、任务或自动配对循环 |
| 同名字幕有 SRT 与 ASS，或同名视频有 MP4 与 MKV | 准备区展示候选列表，选一次后继续；不悄悄按格式或磁盘顺序选首个 |
| 没有匹配、候选不可读或无效 | 主动添加的文件仍可用，显示具体状态及“选择视频/字幕”；不伪装关联成功 |
| 当前工程有内容，新文件将替换它 | 先保存、另开工程或取消；不由自动关联覆盖已有成果 |

自动配对结果是轻量状态提示；“更换”“解除关联”在文件信息旁。文件名很长时可展开看完整目录。纯字幕工程不因没有视频被阻塞。完整匹配规则以[产品方案](product-plan.md)为准。

准备页按需求揭示：

同名外部字幕自动配对先于内封字幕建议和识别设置。已有字幕时默认进入编辑；用户显式选择重新识别才展开模型与音轨设置。

1. 识别到多个音轨：列语言、声道、名称，提供短试听；开始前必须选定。
2. 已有文本字幕：优先提取，可切换识别；图片字幕标明“需要 OCR，当前未支持”。
3. 源语言由用户确认，不用文件名推断已正确。
4. 推荐模式默认给出模型组合，仅展示下载量/存储位置/预计资源；高级区再显示 0.6B、CTC 等技术名称。
5. 点击开始前列出“本地处理”或“将向所选服务发送字幕文本”；不在首次启动就索要 Key。

提供自制、许可清晰的短文本演示工程；没有模型/账号也能体验编辑与导出。演示不包含伪造的真实识别测试结果。

## 4. 工作台布局

### 宽窗口

```text
工程名 · 保存状态      准备  编辑  导出       任务  设置
─────────────────────────────────────────────────────
视频/音频预览            主字幕列表
当前句播放控件           时间 · 原文（可折叠） · 译文
                         全部 / 待审 / 问题 / 已锁定
─────────────────────────────────────────────────────
可折叠波形与字幕时间段     当前句信息 / 下一问题
```

视频与列表支持调整比例。样式、术语、版本差异从侧面按需展开，默认不同时占满屏幕。拖拽分隔条有键盘替代。

### 窄窗口与高 DPI

断点使用 **CSS 有效宽度**，不是物理分辨率。约 1100 CSS px 以下采用上预览、下列表；约 700 以下用列表单列、原文在译文上方，工具收纳入有文字的更多菜单。200% 缩放时不能让 1280 像素窗口仍挤成双栏。

320 CSS px 下文案、设置、错误和主要动作可重排，无整页横向滚动；波形本身允许受控缩放/平移，不把长时间线当普通表格溢出。手机远程查看文档不等于产品提供手机剪辑器。

### 一个列表，而非两套行号

源文与译文通过 cue/atom 来源映射联动。合并后的译文可以对应两条原文，展开时看到真实来源范围。不要让用户在两个 Tab 用相同行号猜对应关系。

默认显示当前编辑语言；“对照”显示同一行内的原文与译文。原始识别、校正原文和优化原文作为明确标注的来源视图，不出现三个同名“原文”面板。

## 5. 编辑规则

| 用户动作 | 界面行为 |
| --- | --- |
| 点时间 | 跳转播放位置，不改变文本焦点 |
| 点正文 | 进入编辑，不因每次光标移动反复跳视频 |
| 输入中文 | IME composition 期间不抢快捷键，不提前提交半个词 |
| 暂停输入 | 显示保存中，收到事务回执后才显示已保存 |
| 用户手动滚动 | 停止播放自动居中，出现“恢复跟随” |
| 改文字/时间/分段 | 对应锁生效，并说明锁保护的范围 |
| 重译选中内容 | 默认仅改译文；预览将影响的 cue 数，保留手改锁 |
| 批量替换 | 先显示匹配范围与替换预览，应用后一个撤销点 |
| 拖动边界 | 显示原值/差值，松手作为一组撤销；同时提供键盘微调 |
| 关闭有草稿的窗口 | 先处理未提交草稿；失败时不直接退出 |

快捷键提供当前句循环、前后句、上下问题、播放速度、撤销/重做、拆分/合并。空格仅在非输入区域控制播放。首次使用不弹十个提示框，帮助集中在快捷键面板和就地说明。

## 6. AI 审阅

候选区只分三类：**可接受、需要确认、处理失败**。置信度未知就说未知，不给一律“95%”的质量分。

- 对比显示具体文字、边界、锁变化；新增/删除不仅靠颜色，辅以符号和文字。
- 重点检查数值/单位、否定、术语、纠错、跨 gap 与删词建议。
- 每项可播放对应片段，接受/拒绝/保留疑问；高风险项不隐藏在总分里。
- “全部接受”只作用于符合规则且当前版本未冲突的候选；会重新校验版本。
- 批量重译运行时继续编辑可以，但旧候选进入冲突待审，不能抢写。
- 审阅状态与内容版本一起保存，改过的句子不能继续显示上次已审。

## 7. 样式与预览

默认提供少量可理解的外观预设，如“清晰白字”“双语对照”“教学底板”；八类翻译风格与字体外观分开，避免“3D 风格”误被理解为立体文字。

常用参数先给字号、位置、描边/底板、主副语言顺序；字体搜索、边距、局部覆盖放高级区。全局样式与单 cue 覆盖有明显作用域；“恢复全局”可撤销。“保存预设”与“设为新工程默认”分开，旧工程不被全局配置追溯改变。

位置按真实内容矩形计算，letterbox 不参与；九宫格与数值输入可替代拖动。视频标明“原片/代理/精确静帧”，HDR 代理标“SDR 预览，非最终色彩”。缺字和预览能力降级就在画布旁提示。

## 8. 导出页

先选结果：“字幕文件”“可开关字幕视频”“固定字幕视频”。然后显示语言轨与目标路径，再展开容器/编码参数。

导出检查分为：

- **必须处理**：非法时间、缺失产物、源文件覆盖、无法保留的关键流未决、格式硬错误。
- **需要确认**：MP4 样式降级、保留阅读警告、字体嵌入限制、未知空间估算。
- **已准备好**：只说明当前检查通过，不声称内容准确率 100%。

主要动作随状态变为“处理问题”“导出 5 秒样片”“开始导出”。完成页提供打开文件、打开目录、查看清单；失败保留工程和已完成结果。大文件封装显示真实字节/阶段，不显示“无损所以秒完成”。

## 9. 错误文案与任务状态

错误按“发生什么 → 哪些成果还在 → 现在可做什么”编写，错误码置于可复制详情。

| 场景 | 面向用户的提示和动作 |
| --- | --- |
| 模型未下载 | 本地识别需要下载模型，已有字幕仍可编辑；选择位置并下载 |
| 401/403 | 当前服务未授权，已完成批次已保存；检查服务设置，不自动换账号 |
| 请求结果未知 | 服务可能已处理并计费；核对账单后选择重试，不直接自动重发 |
| 磁盘满 | 当前阶段无法写入，源文件未改变；选择其他输出位置或清理缓存 |
| 译文过期 | 翻译期间你修改了这些句子；查看差异并选择接受，不覆盖手改 |
| 媒体移动 | 字幕仍在，视频路径失效；重新定位媒体并校验指纹 |
| 播放能力不足 | 改用代理或精确样片；编辑与字幕导出仍可使用 |

阶段已知数量才显示百分比；模型加载等未知阶段用不定进度。ASR 的按钮说“取消当前文件”而不是误导性的实时暂停。任务切页后继续运行，退出策略由用户选择。

## 10. 易用性和可访问性验收

以下是计划门槛，不是已测结果：

- 至少 5 名未接触过项目的目标用户，用 60 秒自制样例完成导入→改一句→导出 SRT；至少 4 人无需口头指导、8 分钟内完成，下载时间单独记录。
- 首要入口验收分别从拖入视频、拖入字幕、添加视频、添加字幕开始；唯一同名配对均无需第二次选文件，最终能看到对应视频和字幕。键盘文件选择与拖放结果一致。
- 不预先解释 soft/hard subtitle，用户仍能正确选出“可关闭”与“固定”两类视频；误选必须在预检能发现。
- 仅键盘完成上述路径及纠正错误，焦点可见、弹窗关闭回到触发点、无键盘陷阱。
- NVDA/Windows 读屏验证列表选择、编辑、错误与进度播报；虚拟列表不让焦点项在滚动时消失。
- 正文对比度目标 4.5:1，大文字及必要非文本控件至少 3:1；状态不只靠颜色。
- 常用点击区目标至少 32 CSS px，紧凑控件不低于 WCAG 2.2 24 px 最小目标要求或满足其间距例外；提供不依赖拖动的替代操作。
- 100%/150%/200% 缩放、浅深色、长译名、混合 RTL/LTR、20000 cue、无网络、无模型状态逐项测试。
- 动效仅用于状态反馈，短时轻量，遵从 reduced-motion；无装饰性悬浮跳动。

参考 [W3C WCAG 2.2](https://www.w3.org/TR/WCAG22/)。上述阈值是工程目标，完整符合性声明须在全流程实测后才发布。
