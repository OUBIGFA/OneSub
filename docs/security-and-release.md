# 安全、隐私与分发

状态：待实现的产品约束 · 2026-10-26

## 1. 数据与网络边界

媒体、字幕、摘要、术语和提示上下文都可能包含私人内容。默认本地存储；联网翻译在执行前显示所选服务、模型、发送内容类别和费用估算。不得把“没有上传视频”写成“没有发送任何数据”。本地服务也要显示其地址与执行位置。

Key 存入操作系统凭据设施，不进入工程、前端持久存储、日志或公开诊断。用户自定义端点不能自动接收另一服务的 Key；重定向到不同来源时禁止转发认证头。TLS 默认验证。代理与企业证书设置不得使整个应用跳过证书检查。

诊断默认只含版本、阶段、错误码、脱敏命令摘要、资源统计和必要哈希。导出前预览并让用户选择是否附加内容。遥测默认关闭，启用范围单独说明。网络失败不能触发换账号或换供应商。

## 2. 输入与进程

媒体、字幕、字体、模型包、工程包和 LLM 输出均是不可信输入。限制大小、控制消息行长和解析时间；解包拒绝绝对路径、上级跳转及链接越界。外部程序使用参数数组，绝不拼 shell 命令。

MyGo 仅绑定专用业务操作；资源服务只允许注册的 mediaId 与短期能力令牌，核查 Host、请求来源与路径边界。CSP 禁止任意远程脚本。字幕和模型文本不能授予文件、命令或网络权限。

工作进程隔离用于故障边界，并不自动提供安全沙箱。Windows Job Object/Unix 进程组只能管理本任务。停止或取消不按进程名清理其他应用。

工程写入由 Go 单点事务控制。输出在目标同卷写唯一 partial 文件，验收后原子发布；源文件、已有成果及其链接别名默认不覆盖。缓存删除只处理明确归属、无活动引用的可再生文件，卸载保留用户工程。

## 3. 许可证清单

OneSub 自有内容采用 AGPL-3.0-or-later。以下仅是规划依据，真正引入前需登记精确版本与全部传递依赖。

| 对象 | 已有依据与限制 | 分发前必须完成 |
| --- | --- | --- |
| MyGo、OneAsr、libse、SmartSub | 研究快照中的相关许可证为 MIT | 保留原版权及许可，核查实际编译依赖和移植范围 |
| Concat | Cargo 清单声明 AGPL-3.0-or-later | 限定项目自有编辑历史/命令逻辑；登记文件、符号及修改；不复制 Slint/vendor/渲染依赖来扩大范围 |
| 字幕翻译技能 | 上游快照无明确 LICENSE；权利人于 2026-10-27 授权其自有内容采用 AGPL-3.0-or-later 随 OneSub 分发 | 保留授权说明、来源 SHA 和原版权；逐项检查第三方术语/夹具，不把此授权扩展到他人内容 |
| JASSUB | 发布清单列出 LGPL、FreeType 双选项和多个宽松许可证的组合 | 登记实际 WASM、字体及全部许可，不能只写包装层 MIT |
| FFmpeg/libass | 条款取决于构建选项和链接内容 | 保存配置、patch、源码和依赖许可；不分发含 nonfree 的不可再分发构建；评估 GPL 组件的组合义务 |
| Qwen、omniASR、SenseVoice、HTDemucs 等模型 | 代码许可证不代表权重许可证；转换版与镜像不是基础模型权利人 | 分别登记权重来源/revision/哈希、上游与转换条款；SenseVoice 使用自定义模型条款，不能统一标成 Apache |
| 字体 | 字体文件另有授权，系统安装不代表可打包 | 核对分发、嵌入、修改和保留名称条款；只随包提供已登记字体 |

分进程、翻译语言或小幅改写都不自动消除第三方许可义务。许可不明的可选组件保持禁用；默认组件许可未解决则阻止产品发布。当前文档仓库的公开不构成对这些组件的再分发。

## 4. 依赖与更新

依赖 manifest 记录项目 URL、精确 commit/tag 解析值、下载 URL、SHA-256、字节数、SPDX/许可文件、用途、构建选项与本地补丁。模型额外记录基础/转换/镜像来源和每个权重文件哈希。研究证据清单不是构建锁文件。

下载写入临时文件，验证长度、哈希和格式后原子安装；保留已验证旧版本。更新检查/下载失败不删除可用组件，不使用浮动 latest 填补缺失依赖。离线导入与联网下载执行同一验证。

升级 Go/Rust/.NET/Python/WebView/FFmpeg 各运行时前，重跑对应平台与协议回归。依赖漏洞扫描需对应真实锁文件；当前没有应用依赖，不能宣称已完成应用供应链审计。

## 5. 产品发行材料

未来每个版本提供签名或平台验证材料、安装包 SHA-256、来源可追溯的 SBOM、第三方许可、完整对应源码及构建说明、支持平台、已知问题和迁移说明。构建日志与大产物放发布资产，不写入 main。

发行在干净环境验证首次运行、无网络、模型未下载、只编辑字幕、取消、升级失败回滚、卸载保留工程。更新签名密钥只在受控发布环境使用，不交给外部 PR。

规划基线先进入公开仓库，随后开发 0.0.1 本地测试安装器。安装器固定文件名和安装标识，构建号与校验和用于区分更新；不宣称签名、分支保护或漏洞私密报告已启用。对外 Release 与产品 tag 独立于本地安装测试，沿用实际授权。仓库检查与 CI 的范围见 [仓库规划](repository-plan.md)。
