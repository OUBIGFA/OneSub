# Windows 工作台完善记录

## 行为与复用

- MyGo `RequestSingleInstanceLock`、`OnSecondInstance`、`Restore/Show/Focus`：重复启动、最小化和托盘隐藏均唤醒原窗口，不创建第二套工作台。
- 子进程经统一入口配置 `CREATE_NO_WINDOW` 与隐藏窗口；Job Object 仍负责长任务的进程树取消。
- SmartSub 字体族别名修复及完整字重交付见 [补丁登记](../../third_party/ports/smartsub/README.md)。系统字体目录元数据变化触发目录刷新，不需要重启；可手工刷新，不重置用户样式。
- 字幕保存采用显式保存和保存／不保存／取消。原文与译文可以独立修改、撤销，原始文字不变；播放跟随不能切走未保存草稿或占用编辑焦点。
- 单击／双击行为参照 Subtitle Edit `SettingsViewModel` 的独立动作设置，提供仅选择、定位保持状态、定位暂停、定位播放。Avalonia UI 未移植到 MyGo。
- 软字幕封装与硬字幕烧录使用通行术语；进度参照 SmartSub `composeRunner` 的真实媒体时间/总时长计算，校验完成前不宣称任务成功。
- 序号列以当前字体测量最大位数，并包含表格内边距。保留完整工程编号容量，不按筛选后的行数收缩。

## 布局回归

文件选择时的“取消任务”按钮原先令状态栏变高，挤压百分比分隔面板。现在状态栏高度稳定，文件窗口不显示后台任务取消按钮。测试比较内部播放器边界，不只比较外层窗口尺寸。

设置按功能分组且四页同高；数值输入不能小于 MyGo 输入框与两个步进按钮的固有宽度，否则相邻标签重叠。播放器纯图标按钮与进度条单行排列，文件名居中。空区域的提示居中并使用主题次要文字色。
